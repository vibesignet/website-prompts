# Website prompts for Claude Code and Codex

Free planning prompts for building a website with an AI coding tool, from [Vibesignet](https://vibesignet.com). Each one is a prompt you paste into Claude Code, Codex, Cursor or any coding agent before it writes a line of code.

Most AI-built sites look alike because the brief is vague, and a vague brief returns the average of every site the model has seen. These prompts make the decisions first: who the site is for, what it must do, and what it should look like.

## The prompts

| Prompt | What it does | Time |
|---|---|---|
| [01 The brief](prompts/01-brief/prompt.md) | Six lines on the business, then the AI questions you before proposing anything | 20 to 30 minutes |
| [02 Three directions](prompts/02-three-directions/prompt.md) | Three visual directions that differ in kind, with colours, type and a recommendation | 30 to 45 minutes |
| [03 A hero that does something](prompts/03-hero/prompt.md) | A complete build prompt for an interactive first screen, with a [live demo an AI coding agent built from it](https://vibesignet.com/website-prompts/demo/) (one change since: the slider) | 60 to 90 minutes |

The times are our estimates for a first build, not measurements. All three are also on [vibesignet.com/website-prompts](https://vibesignet.com/website-prompts), with copy buttons.

## How to use them

1. Open Claude Code or Codex in an empty project folder.
2. Paste prompt 01, fill in the brackets, and answer its questions.
3. Paste prompt 02 in the same session. Pick one direction.
4. Paste prompt 03 with your business and your own idea in place of the paint mixer.

The full method has seven steps, from brief to phone test: [How to build a website with Claude Code: the 7 honest steps](https://vibesignet.com/guides/build-a-website-with-claude-code).
